=====================
Partner Gender Values
=====================

This module adds a fourth option, "I prefer not to say", to the gender
field that ``partner_contact_gender`` puts on contacts.

Configuration
=============
\-

Usage
=====

#. Open a contact's Personal Information tab.
#. The Gender field now also offers "I prefer not to say" alongside Male,
   Female and Other.
