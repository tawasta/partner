==========================
Partner Factoring Reminder
==========================

This module adds a reminder when creating a new contact.

When a user attempts to save a newly created contact, a confirmation dialog is displayed reminding the user to verify the customer's factoring status before proceeding.

The reminder is intended as a lightweight safeguard to reduce the risk of forgetting the factoring check during customer onboarding.


Configuration
=============

No configuration is required.

Usage
=====
#. Open **Contacts**.
#. Create a new contact.
#. Click **Save**.
#. A confirmation dialog is displayed with the message:

   *"Have you remembered to check Factoring?"*

#. Select **Continue Saving** to proceed or **Cancel** to return to the form.
