=========================================
Partner: Primary Contact for Organization
=========================================

* Adds simple 'Primary Contact' checkbox to contacts
* Intended for situations where a tag is not enough, 
  e.g. if you want to restrict partner's user's access
  based on this information.

Configuration
=============
* None needed

Usage
=====
* Open contact form to see the new field
