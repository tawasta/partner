====================================================
Version number and an additional ID info of partners
====================================================

::

    Adds two new fields to partners:
    - Version (technical name: version_number)
    - ID info (technical name: id_number_info)

    These fields have no other functionalities than to be informative.
    Note that an end user cannot see these fields in partner form view.

Configuration
=============
There is no need to configure anything

Usage
=====
Go to Apps to install the module. Add data to the new fields.

Known issues / Roadmap
======================
While making this module no other fields exist (in partners of in other models
for that matter). Maybe check if this is the case in future versions.
