==========================
Contact view immprovements
==========================

::

    Reference information of a contact is a bit hidden from users
    in Odoo. This module shows Reference in form view immeadiately
    after opening a contact. Reference is shown in tree view also
    and it is added as a search field to better filter contacts.

Configuration
=============
::

    There is no need to configure anything

Usage
=====
::

    Install the module from Apps

Known issues / Roadmap
======================
::

    Tree, form and search views are changed, but this will not create any issues
