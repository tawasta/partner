=====================================
Partner: Economic Development Centres
=====================================

* Adds option to freely define geographic regions and link partners to them
* A simple module intended for situations where  e.g. OCA's 
  base_location_nuts uses a different classification than what you 
  need for e.g. reporting

Configuration
=============
* None needed

Usage
=====
* New field is shown in partner form view
* Geographic regions can be managed in Contacts -> Settings
